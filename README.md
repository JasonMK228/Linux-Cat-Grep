# Cat & Grep linux 

Проект в рамках обучения в Школе 21. Реализация утилит cat и grep на языке С с поддержкой основных флагов регулярных выражений

## Описание
Данный проект представляет собой реализацию двух базовых утилит командной строки Linux:
  s21_cat - утилита для вывода содержимого файлов
  s21_grep - утилита для поиска текста по шаблону
Обе программы разработаны на языке С (стандарт С11) с соблюдением принципов структурного программирования.

## Функциональность
### s21_cat
Поддерживаемые флаги:
  * -b - нумерация только непустых строк
  * -e - отображение символов конца строки как $ (включает -v)
  * -E - отображение символов конца строки как $
  * -n - нумерация всех строк
  * -s - сжатие нескольких смежных пустых строк в одну
  * -t - отображение табуляции как ^| (включает -v)
  * -T - отображение табуляции как ^|
  * -v - отображение непечатаемых символов

### s21_grep
Поддерживаемые флаги:
  * -e — указание шаблона регулярного выражения
  * -i — игнорирование регистра
  * -v — инвертирование поиска (вывод строк без совпадений)
  * -c — вывод только количества совпадающих строк
  * -l — вывод только имён файлов с совпадениями
  * -n — вывод номера строки перед совпадением

## Требования

  * Компилятор GCC с поддержкой C11
  * POSIX-совместимая система (Linux/macOS)
  * Библиотека regex.h (входит в стандартную библиотеку C)
  * Bash для запуска тестов
## Сборка
Сборка s21_cat:
```
cd src/cat
make
```
Сборка s21_grep:
```
cd src/grep
make
```
Очистка:
```
make clean
```
Запуск тестов:
```
chmod +x tests/test_cat.sh
chmod +x tests/test_grep.sh

./tests/test_cat.sh

./tests/test_grep.sh
```
